Ensamblaje
=========================

**Descripción general**

Si desea aprender mientras ensambla los diversos componentes, puede consultar :ref:`programming_arduino`. En este capítulo, cada lección incluye videos de ensamblaje, principios de los componentes y código de prueba relacionado, lo que le permite aprender sobre la marcha. Por lo tanto, puede omitir este capítulo.

Si desea ensamblar rápido y comenzar a jugar, primero puede ver el video de ensamblaje. Después de completar el ensamblaje, continúe con :ref:`quick_start` para conocer la instalación y conexión de la aplicación. Luego, puede usar la aplicación para controlar el GalaxyRVR.
