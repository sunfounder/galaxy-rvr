Arduino IDE でプログラミング
=================================
構造化された13のレッスンで、マーズローバーの内部動作を探求し、その機能をカスタマイズしましょう。火星ローバーの歴史から始まり、主要コンポーネントの実践的な組み立てと統合に取り組みます。

ビデオ、実践的なレッスン、詳細なガイドを通じて、GalaxyRVRを動かす力学、電子機器、ソフトウェアについて包括的な理解を得ることができます。最後には、完全に組み立てられたローバーと、トラブルシューティング、変更、革新を行うスキルを身につけることができます。

赤い惑星を身近に感じる準備をしましょう。今すぐローバーアドベンチャーを始めましょう！

**コードをダウンロード**


以下のリンクから関連するコードをダウンロードしてください。


    * |download_galaxyrvr_code|

または、|link_github_galaxyrvr| でコードを確認できます。
