レッスン1 マーズローバーの謎を解き明かす
========================================

レッスン1「マーズローバーを理解する」へようこそ。今日は、私たちの赤い惑星における遠隔探査機であるマーズローバーのスリリングな世界に飛び込みます。ローバーの進化、機能、そしてその技術的驚異について学びます。さらに、創造力を発揮して自分だけのローバーを設計し、そのユニークなデザインを説明することでプレゼンテーションスキルを磨きます。教室から火星探査に出発する準備をしましょう！


学習目標
-------------------------
* マーズローバーの進化と目的についての理解を深める
* 自分だけのマーズローバーを設計することで創造性を表現する
* ローバーのデザインを共有・説明することでプレゼンテーションスキルを向上させる

必要な材料
-----------
* 参考用のマーズローバーの画像と技術仕様
* マーズローバーの歴史に関するドキュメンタリービデオ
* 調査やドキュメンタリー視聴のためのインターネット接続が可能なコンピューター
* 授業用のプレゼンテーションスライドまたはインタラクティブホワイトボード
* ローバーデザイン活動のための画用紙、鉛筆、着色材料
* ガイド付きノート作成、振り返り、デザイン計画のためのワークシート

手順
--------------

**ステップ1: マーズローバーとは？**

マーズローバーについて詳しく見る前に、まず火星自体について知りましょう。画像やモデルからわかるように、火星の表面はクレーター、山々、谷、砂嵐によって特徴づけられ、魅力的でありながらも挑戦的な風景を描き出しています。

    .. image:: img/mars_surface.jpg
        :width: 600
    .. image:: img/mars_surface.png
        :width: 600

このような起伏の多い地形を移動するとはどのようなことか、想像できますか？では、あなたが火星用のローバーを設計する任務を負ったと仮定しましょう。

* 火星の地形と条件を考慮して、どのような点に注意しますか？
* その機能を効果的に果たせるように、どのような機能を装備させますか？
* あなたのマーズローバーはどのような任務を達成する必要があると思いますか？

マーズローバーは火星を探査し、その環境を研究し、データを地球に送信するために設計されたロボットです。ですので、移動、通信、電源供給、科学研究能力、火星の過酷な条件下での耐久性などの側面について考えてみましょう。

少し時間を取って、アイデアをブレインストーミングし、共有しましょう。エンジニアや科学者のように考えるのは面白いですね？次のステップでは、実際のマーズローバーの設計とその機能についてさらに深く掘り下げますので、進めていく中で創造的なアイデアを心に留めておいてください。


**ステップ2: マーズローバーの歴史を探る**

次に、マーズローバーの歴史を詳しく紹介するドキュメンタリーを見ながら、時空を超えた旅に出発します。このドキュメンタリーでは、1971年に火星に着陸したものの成功しなかったソビエトのマーズ3ローバーから、1997年のNASA初の成功したマーズローバーであるソジャーナまでを追います。

私たちの旅はそこで終わりません。さらに進んで、これまでで最も先進的なローバーであるスピリット、オポチュニティ、キュリオシティ、パーサヴィアランスの冒険を理解していきます。

このドキュメンタリーは、歴史的な背景を提供するだけでなく、現在の火星探査時代につながる progressive な科学的・工学的マイルストーンについての包括的な理解を提供します。


**ステップ3: マーズローバーのまとめ**

ドキュメンタリーを見た後、赤い惑星に送られた様々なマーズローバーをまとめてみましょう。

* **ソジャーナ** (1997)

    **ソジャーナ** は、マーズローバーの先駆けとして、マーズ・パスファインダーミッションの一部として旅立ちました。1997年7月4日、アレス・ヴァリス地域への着陸に成功しました。地球以外の惑星を走行した最初の車輪付き車両として、ソジャーナは火星探査において重要なマイルストーンとなりました。火星での運用はわずか92ソル（火星日）でしたが、将来の探査ローバーの基礎を築きました。

    .. image:: img/mars_sojourner.jpg

* **スピリット** (2004–2010) と ** オポチュニティ** (2004–2018)

    **スピリット** と **オポチュニティ** は、NASAの火星探査ローバー（MER）ミッションの双子のローバーです。 **スピリット** （MER-Aとしても知られる）は、2004年から2010年まで火星で運用されました。

    一方、 **オポチュニティ** （MER-B）は、2004年から2018年まで非常に長い期間運用されました。この2台は共に、火星表面と地質学的歴史についての理解を大きく拡大しました。

    .. image:: img/mars_opportunity.jpg

* **キュリオシティ** (2012年–現在):

    **キュリオシティ** は、車サイズのマーズローバーで、NASAの火星科学研究所（MSL）ミッションの一環として火星のゲイル・クレーターを探査するために設計されました。2012年の到着以来、 **キュリオシティ** は、火星にかつて液体の水が存在した証拠など、数多くの重要な発見をしてきました。

    .. image:: img/mars_curiosity.jpg

* **パーサヴィアランス** (2021年–現在):

    **パーサヴィアランス** （パーシーとしても知られる）は、火星に到着した最新のローバーです。NASAの火星2020ミッションの一環として、ジェゼロ・クレーターを探査するよう設計されています。科学機器に加えて、 **パーサヴィアランス** は小型の実験用火星ヘリコプターであるインジェニュイティも搭載しており、火星探査におけるまた別の先駆けとなっています。

    .. image:: img/mars_perseverance.jpg

では、話し合いをしましょう。これらのローバーの進化について振り返ってみてください。

* これらのローバーのデザインはどのように異なっていますか？どのように似ていますか？
* ミッションの目的は各ローバーの設計にどのような影響を与えましたか？
* 各ローバーの間で、どのような技術の進歩を確認できますか？
* 次のマーズローバーにはどのような機能が必要だと思いますか？
* あなたの考えや感想、そして質問があれば共有しましょう！

**ステップ4: アート活動: 自分だけのマーズローバーを描こう**

.. image:: img/sojourner-first.jpg
.. image:: img/spirit-opportunity.jpg
    :width: 500
.. image:: img/curiosity.png
.. image:: img/perseverance_rover.png

次の活動では、これまで学んだ知識と創造性を活かして、自分だけのマーズローバーを設計してみましょう。これまでに学んだローバーの主な特徴を考慮しつつ、自分のデザインに取り入れたいユニークな属性についても考えてみてください。

必要な材料:

* 画用紙
* 鉛筆と消しゴム
* 色鉛筆、クレヨン、またはマーカー

描画手順:

#. ローバーの車体から始めましょう。どんな形にしますか？どのくらいの大きさにしますか？
#. 車輪について考えましょう。ローバーにはいくつの車輪がありますか？どのような大きさと形にしますか？
#. 計器類も忘れずに。ローバーにはどのような科学機器を搭載しますか？カメラ、ドリル、分光計、またはまったく新しい何かですか？
#. 最後に、ユニークな機能を考えてみましょう。ローバーにはソーラーパネルがありますか？それとも別の電源を使用しますか？地球と直接通信できますか？それとも中継衛星が必要ですか？

全員が描き終えたら、クラスで共有しましょう。自分のデザインの選択と、ローバーに想定するミッションについて説明してください。

**ステップ5: マーズローバーのデザインを発表しよう**

全員がマーズローバーの絵を完成させたので、共有する時間です！発表する際には、デザインの背後にある思考プロセスについて説明してください。あなたのローバーのミッションは何ですか？デザインはどのようにそのミッションをサポートしていますか？

この活動に間違った答えはありません。目的は、創造性を刺激し、マーズローバーの技術についての理解を深めることです。

**ステップ6: 振り返りとまとめ**

マーズローバーのレッスンを締めくくるにあたり、学んだことを振り返る時間を取りましょう。私たちのローバーのデザインは、技術の進歩や科学的目的をどのように反映していますか？実際のマーズローバーは将来、どのように進化し続けるでしょうか？

宇宙の探検は、他のすべてのSTEAM分野と同様に、質問をすること、問題を解決すること、そして創造性を活用することです。探検を続け、質問を続け、そして好奇心を持ち続けてください！
