
Lektion 2: Erste Schritte mit der Mammoth Coding-App
===============================================================

Tauchen wir ein in die Welt von Mammoth Coding und erstellen Sie Ihr erstes Projekt! Für ein optimales Erlebnis wird die Verwendung eines Gerats mit gro?erem Bildschirm empfohlen.

Lernziele
----------------------

* Die Programmierungsumgebung von Mammoth Coding einrichten.
* Grundlegende Programmierkonzepte in Mammoth Coding verstehen.
* Ihr erstes Programm schreiben und ausführen.

      :width: 600

Die App verstehen
-----------------------------------

Mammoth Coding ist darauf ausgelegt, unterhaltsam, lehrreich und leicht zu erlernen zu sein. Es bietet Werkzeuge zum Erstellen interaktiver Geschichten, Spiele, Kunst, Simulationen und mehr mit blockbasierter Programmierung. Es enthalt au?erdem integrierte Zeichen- und Sound-Editoren.

Oberer Bereich
^^^^^^^^^^^^^^

Der obere Bereich von Mammoth Coding enthalt mehrere wichtige Optionen.

.. image:: img/1_app_ui_1.png
   :align: center

* **Spracheinstellungen**: Die erste Option auf der linken Seite ermoglicht es Ihnen, verschiedene Sprachen auszuwahlen. Derzeit sind Englisch und vereinfachtes Chinesisch verfugbar.
* **Dateimenu**: Die zweite Option ist das **Datei**-Menu, in dem Sie neue Projekte erstellen, vorhandene öffnen und Ihr aktuelles Projekt speichern können.
* **Projektname**: Die dritte Option ermoglicht es Ihnen, Ihr Projekt umzubenennen.

Ihr erstes Programm erstellen
----------------------------------------

1. Ein Projekt erstellen oder öffnen
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


* Jedes Mal, wenn Sie die Mammoth Coding-App öffnen, wird automatisch ein neues Projekt erstellt.

  .. image:: img/1_open_new.png
     :width: 600

* Andern Sie den Standard-Projektnamen "Mein Projekt" in einen aussagekraftigeren Namen.

  .. image:: img/1_new_name.png
     :width: 600

* Sie können auch ein Projekt öffnen, das Sie zuvor auf Ihrem Gerat gespeichert haben.

  .. image:: img/1_new_save.png
     :width: 600

2. Eine Figur auswahlen
^^^^^^^^^^^^^^^^^^^^^^^^^

* Wenn Sie ein neues Projekt starten, wird eine Standardfigur bereitgestellt. Sie können:

  * Die Standardfigur verwenden.
  * Eine neue Figur aus der Bibliothek auswahlen.
  * Ihre eigene Figur zeichnen.
  * Eine Figur von Ihrem Gerat hochladen.

  .. image:: img/1_choose_sprite.png

* So wahlen Sie eine neue Figur aus: Tippen Sie auf **"Figur auswahlen"** und wahlen Sie **"GalaxyRVR"** aus.

  .. image:: img/1_choose_galaxyrvr.png

3. Das Programm schreiben
^^^^^^^^^^^^^^^^^^^^^^^^^^^^

In der linken Seitenleiste finden Sie verschiedene Kategorien mit unterschiedlichen Blocken. Sie können Blocke aus diesen Kategorien in den Skriptbereich ziehen, um Ihr Programm zu erstellen.

Um beispielsweise die **GalaxyRVR**-Figur bei Klick auf die grune Flagge 10 Schritte vorwarts bewegen und dann zum nachsten Kostum wechseln zu lassen:

1. Ziehen Sie aus der Kategorie **Ereignisse** den Block **"Wenn grune Flagge angeklickt"** in den Skriptbereich.

     .. image:: img/1_code_flag.png
        :width: 600

2. Ziehen Sie aus der Kategorie **Bewegung** den Block **"gehe (10)er-Schritt"** und setzen Sie ihn unter den Ereignisblock.

     .. image:: img/1_code_move10.png
        :width: 600

3. Ziehen Sie aus der Kategorie **Aussehen** den Block **"nachstes Kostum"** und fugen Sie ihn unter dem Bewegungsblock ein.

     .. image:: img/1_code_next.png
        :width: 600

4. Das Programm ausführen
^^^^^^^^^^^^^^^^^^^^^^^^^^^

Es gibt zwei Moglichkeiten, Ihr Programm auszuführen:

1. Tippen Sie einfach auf den Blockstapel, den Sie im Skriptbereich zusammengesetzt haben. Eine gelbe Hervorhebung erscheint und zeigt an, dass das Skript lauft.

     .. image:: img/1_code_run.png
        :width: 30%

2. Wenn Ihr Skript mit dem Block **"Wenn grune Flagge angeklickt"** beginnt, können Sie auf die grune Flagge oben links auf der **Buhne** klicken, um Ihr Programm auszuführen. Dies wird für Projekte mit mehreren Figuren oder komplexerem Code empfohlen.

     .. image:: img/1_code_green_flag.png
        :width: 70%

5. Ihr Projekt speichern
^^^^^^^^^^^^^^^^^^^^^^^^^

Nachdem Sie Ihren Code getestet und sichergestellt haben, dass alles korrekt funktioniert, ist es wichtig, Ihr Projekt zu speichern.

1. Klicken Sie auf das Speichern-Symbol rechts neben dem Projektnamen.

     .. image:: img/1_code_save.png
        :width: 600

2. Eine Meldung "Projekt gespeichert" erscheint. Das Projekt wird in der Mammoth Coding-App gespeichert. Sie können auf Ihre gespeicherten Projekte zugreifen, indem Sie auf das Menusymbol ganz rechts klicken.

     .. image:: img/1_code_save_app.png
        :width: 600

3. Um Ihren Code zu teilen oder auf Ihrem Gerat zu speichern, klicken Sie auf **Datei > Auf Ihrem Gerat speichern** und wahlen Sie dann eine Anwendung zum Teilen aus oder speichern Sie das Projekt auf Ihrem mobilen Gerat.

     .. image:: img/1_code_save_device.png
