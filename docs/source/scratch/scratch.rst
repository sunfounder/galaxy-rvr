Programmazione con Scratch
============================

Oltre alla programmazione nell'IDE Arduino, possiamo anche utilizzare la programmazione grafica.

Consigliamo di utilizzare Scratch per la programmazione.
Tuttavia, Scratch ufficiale attualmente supporta solo Raspberry Pi. Per risolvere questo problema, abbiamo sviluppato Mammoth Coding,
un software di programmazione grafica basato su Scratch 3, specificamente per schede Arduino (Uno, Mega2560 e Nano).

Mammoth Coding mantiene le funzionalità di base di Scratch 3 aggiungendo la capacità di controllare varie schede come Arduino Uno,
Mega, Nano e schede personalizzate. Ti permette di utilizzare sensori esterni e robot per controllare gli sprite sul palco, offrendo robuste capacità di interazione hardware.

Inoltre, questa app è facile da usare anche se non hai molta esperienza di programmazione. Puoi imparare e utilizzare queste tecnologie all'avanguardia con facilità.

Trascina e rilascia semplicemente i blocchi di codifica Scratch per creare giochi emozionanti, animazioni, progetti interattivi e persino controllare i robot esattamente come li immagini!

Iniziamo questo viaggio di esplorazione ora!
