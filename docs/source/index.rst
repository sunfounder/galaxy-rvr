荒涼とした火星の地形をローバーで操縦し、異星の風景を探索し、未知の世界に立ち向かう——そんな夢を想像したことはありますか？まるでNASAのエンジニアのようですね。

もう夢ではありません。

GalaxyRVR へようこそ。SunFounder のマーズローバーキットが、惑星間探査をあなたのリビングルームにお届けします。

.. image:: img/galaxyRVR.jpg
    :width: 500
    :align: center

NASA のロッカーボギーシステムを採用した GalaxyRVR は、岩山、砂浜、芝生の上でもスムーズに走行し、まるで火星が故郷のように感じられます。

高解像度カメラを搭載した GalaxyRVR は、一人称視点での没入感あふれる操縦体験を提供します。高度な障害物回避モジュールと超音波モジュールにより、自律的に障害物を回避できます。

興味やスキルレベルに応じて、以下のパスをお選びください：

* :ref:`quick_start` : RoboPilot アプリで GalaxyRVR をすぐに操作したり、Arduino IDE や Mammoth Coding でサンプルコードを素早く実行できます。すぐにハンズオンで操作したい初心者に最適です。

* :ref:`programming_arduino` : コードを深く掘り下げ、各機能を理解し、Arduino プログラミングで GalaxyRVR をカスタマイズできます。深い知識と実験を求める方に最適です。

* :ref:`programming_scratch` : Scratch を使用して GalaxyRVR をプログラミングします。初心者やコーディングに初めて挑戦する方に最適なビジュアルブロック型言語です。
