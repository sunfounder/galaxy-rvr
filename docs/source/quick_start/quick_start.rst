クイックプレイ
===================

この章では、GalaxyRVR をすぐに使い始めるための手順を説明します。
RoboPilot アプリで操作するか、Arduino IDE や Mammoth Coding で既製のサンプルコードを実行できます。コーディングは不要です。

GalaxyRVR は 3 つの制御方法をサポートしています：

- **RoboPilot App** ：モバイルデバイスから GalaxyRVR を運転および操作します。
- **Arduino IDE** ：サンプルコードを開いてアップロードし、ローバーを制御します。
- **Mammoth Coding** ：ドラッグ＆ドロップブロックを使用してサンプルプロジェクトを読み込んで実行します。

上記のいずれかの方法を選択して、GalaxyRVR の操作を開始できます。
