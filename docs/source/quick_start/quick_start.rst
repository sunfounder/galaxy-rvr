Inicio Rápido
===================

Este capítulo te ayuda a comenzar a usar tu GalaxyRVR rápidamente.
Puedes controlarlo con la aplicación RoboPilot o ejecutar los códigos de ejemplo ya preparados en Arduino IDE o Mammoth Coding, sin necesidad de programar.

GalaxyRVR admite tres métodos de control:

- **Aplicación RoboPilot**: Conduce y opera el GalaxyRVR desde tu dispositivo móvil.
- **Arduino IDE**: Abre y carga códigos de ejemplo para controlar el rover.
- **Mammoth Coding**: Usa bloques de arrastrar y soltar para cargar y ejecutar proyectos de ejemplo.

Puedes elegir cualquiera de los métodos anteriores para empezar a controlar tu GalaxyRVR.
