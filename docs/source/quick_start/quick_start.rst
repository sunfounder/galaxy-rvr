Schnellstart
===================

Dieses Kapitel hilft Ihnen, die ersten Schritte mit Ihrem GalaxyRVR zu machen.
Sie können ihn mit der RoboPilot-App steuern oder die fertigen Beispielcodes in der Arduino IDE oder in Mammoth Coding ausführen – ganz ohne Programmierkenntnisse.

GalaxyRVR unterstützt drei Steuerungsmethoden:

- **RoboPilot-App**: Fahren und bedienen Sie den GalaxyRVR von Ihrem Mobilgerät aus.
- **Arduino IDE**: Öffnen Sie Beispielcodes und laden Sie sie hoch, um den Rover zu steuern.
- **Mammoth Coding**: Verwenden Sie Drag-and-Drop-Blöcke, um Beispielprojekte zu laden und auszuführen.

Sie können eine der oben genannten Methoden wählen, um mit der Steuerung Ihres GalaxyRVR zu beginnen.

----

**Code herunterladen**

Laden Sie die Beispielcodes über den folgenden Link herunter:

    * |download_galaxyrvr_code|

Oder erkunden Sie sie auf |link_github_galaxyrvr|.
