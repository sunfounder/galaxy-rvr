Jeu Rapide
===================

Ce chapitre vous aide à démarrer rapidement avec votre GalaxyRVR.
Vous pouvez le contrôler avec l'application RoboPilot ou exécuter les codes d'exemple prêts à l'emploi dans l'IDE Arduino ou Mammoth Coding — aucune programmation requise.

GalaxyRVR prend en charge trois méthodes de contrôle :

- **Application RoboPilot** : Pilotez et contrôlez le GalaxyRVR depuis votre appareil mobile.
- **Arduino IDE** : Ouvrez et téléversez des codes d'exemple pour contrôler le rover.
- **Mammoth Coding** : Utilisez des blocs glisser-déposer pour charger et exécuter des projets d'exemple.

Vous pouvez choisir l'une des méthodes ci-dessus pour commencer à contrôler votre GalaxyRVR.
