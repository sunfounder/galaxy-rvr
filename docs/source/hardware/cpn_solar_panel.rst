ソーラーパネル
=======================

.. image:: img/solar_panel.png
    :width: 400
    :align: center

ソーラーパネルは、太陽光を電気に変換する装置です。これらは、シリコンなどの半導体材料でできた光起電（PV）セルで構成されています。太陽光が PV セルに当たると、電子が原子からはじき出されます。これらの電子がセル内を流れ、電流を生成します。

ソーラーパネルは、家庭、企業、さらには地域社会全体への電力供給など、さまざまな目的で電力を生成するために使用できます。これらはクリーンで再生可能なエネルギー源であり、化石燃料への依存を減らすのに役立ちます。


**特徴**


* 出力電力: 6V/660mA
* バッテリーを完全に充電する時間: 7.2h（理論値、強い日差しを想定）
* サイズ: 170mm x 170mm
* 配線: 灰色と黒色、24AWG、200mm
* コネクタ: 白色、XH2.54-2P
