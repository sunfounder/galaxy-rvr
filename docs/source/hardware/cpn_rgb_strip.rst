4 RGB LED ストリップ
====================

.. image:: img/4_rgb_strip.jpg


* **+5V**: 3 つの LED の共通アノードで、DC 5V に接続する必要があります。
* **B**: 青色 LED のカソード
* **R**: 赤色 LED のカソード
* **G**: 緑色 LED のカソード

この RGB LED ストリップは 4 つの R5050 RGB LED を備えており、赤、青、緑の 3 原色を組み合わせることで、あらゆる色合いを作り出すことができます。

R5050 RGB LED は、共通アノード構成で設計されています。ストリップ上の各 LED は独立した回路として機能するため、指定されたポイントでストリップを切断しても、他の部分に影響を与えることはありません。ストリップの柔軟性と適応性は、両面接着剤で裏打ちされた FPC ボード上に構築されていることで強化されており、簡単に取り付けることができます。


**R5050 RGB LED とは？**

R5050 RGB LED は、赤、青、緑の発光ダイオードを 1 つのパッケージに組み合わせた LED の一種です。このパッケージ内の各 LED には独自のピンがあり、個別に制御できます。この構成により、各 LED の強度を変えることで、幅広い色を生成できます。

.. image:: img/rgb_5050.jpg
    :width: 400

.. image:: img/rgb_5050_sche.png
    :width: 200

一般的なアプリケーションでは、複数の R5050 RGB LED がスマートな構成でフレキシブル回路に配置されます。これは、すべての LED の「プラス」端（アノード）を一緒に接続し、「マイナス」端（カソード）をそれぞれの色のラインに接続することで行われます。つまり、すべての緑のカソードが一緒に接続され、すべての赤のカソードが一緒に接続され、すべての青のカソードが一緒に接続されます。この配置により、カラーミキシングと光の強度の効率的な制御が可能になり、これらの LED は、装飾照明、看板、ディスプレイ技術など、カスタマイズ可能なカラー照明が望まれるアプリケーションで人気があります。

.. image:: img/rgb_strip_sche.png



**特徴**

* 動作電圧: DC5V
* 色: フルカラー RGB
* 動作温度: -15-50
* RGB タイプ: 5050RGB
* 電流: 150mA（単回路）
* 電力: 1.5W
* ライトストリップ厚さ: 2mm
* ライトストリップ幅: 5.5mm
* ケーブル: ZH1.5-4P、25cm、28AWG、黒
